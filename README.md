# ACADEX — Amir Slides website

This is the responsive Arabic-first redesign for ACADEX academic service orders.

## Files
- `index.html` — home, services, request, contact, and demo tracking sections.
- `styles.css` — responsive blue/white visual design.
- `script.js` — service preselection, language toggle, form submission, demo tracking notice.
- `config.js` — public configuration for your order-receiving endpoint.
- `assets/acadex-logo.jpg` — supplied ACADEX logo image.

## Before publishing
1. Set `formEndpoint` in `config.js` to a real, tested form-backend URL.
2. Submit a test order and confirm it arrives at `goldennarthur@gmail.com`.
3. The tracking form is only a visual/demo interaction until connected to an orders database.
4. Add the WhatsApp number before activating that link.
5. Upload these files to the repository root, keeping the `assets` folder.
